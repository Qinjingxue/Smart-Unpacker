# Repair Training 体系说明

当前训练体系采用“通用 core + 格式插件”结构。通用流程只负责 runtime graph 采集、模型训练、run 目录管理和报告调用；各格式的样本生成、损坏分布、oracle/报告扩展由 `repair_training/formats/<format>/` 插件提供。

## 目录结构

- `repair_training/core/`：格式无关训练核心。
- `repair_training/formats/zip/`：ZIP 专家模型训练插件、ZIP 损坏生成和 ZIP 专项分析。
- `repair_training/material/<format>/`：生成后的损坏样本。
- `repair_training/source_material/`：源样本。
- `repair_training/runs/<format>/<run>/`：数据集、模型、报告、日志和临时工作区。
- `repair_training/latest_runs.json`：按格式记录最新 run。

## 常用命令

生成 ZIP 损坏样本：

```powershell
python -m repair_training.formats.zip.build_material --formats zip
```

采集 ZIP runtime graph：

```powershell
python -m repair_training.core.collect_runtime_graph --format zip
```

训练 ZIP policy 模型：

```powershell
python -m repair_training.core.train_policy --format zip
```

便利 PowerShell 入口仍保留，并统一支持 `-Format`：

```powershell
.\repair_training\build_material.ps1 -Format zip
.\repair_training\collect_plan_data.ps1 -Format zip
.\repair_training\collect_plan_data_parallel.ps1 -Format zip
.\repair_training\train_offline_rl_full.ps1 -Format zip
```

## ZIP 插件边界

ZIP 专属逻辑只放在 `repair_training/formats/zip/`：

- `plugin.py`：ZIP 默认预算、训练目标、模型输出目录、record context、报告 hook。
- `build_material.py` / `build_material_impl.py`：ZIP 损坏样本生成入口和实现。
- `corruption.py` / `corruption_impl.py`：ZIP mutation 和 oracle helper。
- `distributions/`：ZIP 损坏分布。
- `analysis/`：ZIP 专项诊断脚本。

通用 core 不应引用 ZIP profile、ZIP mutation 或 ZIP distribution 名称。

## 新格式接入

新增格式时创建 `repair_training/formats/<format>/plugin.py`，实现 `TrainingFormatPlugin`，并按需增加该格式自己的 material builder、corruption helper 和 report 扩展。核心采集和训练命令不需要改，只需传入 `--format <format>`。
